## 🎨 نظام التصميم (Design System)

### لوحة الألوان (Color Palette)
- --obsidian: #0A0A0B  — خلفية الصفحة
- --gold: #E9C349      — العناوين والعناصر البارزة
- --gold-deep: #D4AF37 — الأزرار والحدود
- --silver: #E4E2E4    — النصوص الأساسية

### الخطوط (Typography)
- العناوين الرئيسية: Playfair Display (خط فاخر)
- النصوص والواجهات: Almarai (خط Google عربي/لاتيني)

---

## ✨ المميزات (Features)

- صورة شخصية بهالة WebGL Shader تفاعلية
- شبكة Bento للخبرات (7 بطاقات بتأثيرات Hover ثلاثية الأبعاد)
- شريط تنقل علوي (Glassmorphism) + شريط سفلي عائم للهاتف
- محول لغة عربي / إنجليزي مع دعم RTL/LTR
- نموذج تواصل بتحقق من المدخلات
- تأثيرات Scroll Animation (fade-up, stagger)
- جميع الروابط الخارجية آمنة (rel=noopener noreferrer)
